kenapa thorhub

Inti layanan, dirancang untuk dipakai terus

// 01

Drop-in OpenAI

Arahkan base_url ke ThorHub dan SDK yang sudah Anda pakai langsung jalan. Streaming, tool calls, dan JSON mode diteruskan apa adanya.

// 02

Kuota per key

Setiap member punya API Key dengan plafon token sendiri. Pantau pemakaian, blokir, atau top-up kapan saja.

// 03

Harga transparan

Konsumsi dihitung auditable lewat multiplier per model — jumlah token yang terpotong dari kuota selalu bisa ditelusuri.

// 04

Tanpa rate limit

Request diteruskan tanpa pembatasan RPM maupun antrean — setiap permintaan diproses langsung ke provider.

// 05

Tanpa lock-in

Endpoint standar /v1/chat/completions dan /v1/models. Pindah provider cukup ganti satu URL.
