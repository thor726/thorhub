  2. API Provider → pilih OpenAI Compatible.
  3. Base URL → …
  4. API Key → sk-thor-xxxxxxxx

Perhitungan Token & Multiplier

Setiap request dipotong dari kuota dengan rumus:

(prompt_tokens + completion_tokens) × multiplier

Contoh: 800 prompt + 1.200 completion pada model 1.5× → (800 + 1200) × 1.5 = 3.000 token dipotong.

Request yang gagal sebelum provider menjawab (timeout/error) tidak dihitung.

Standar OpenAI: choices[].message.content, usage.total_tokens.

Batasan & Catatan

  • Gateway berjalan tanpa batas rate limit (unlimited) — tidak ada pembatasan request per menit atau per paralel. Setiap request langsung diteruskan ke provider.
  • Timeout request ke provider: 120 detik.
  • Body request maksimal 8 MB.
  • Semua parameter OpenAI (temperature, max_tokens, tools, dst.) diteruskan apa adanya.
  • Kuota dihitung per key — hubungi admin untuk top-up.
